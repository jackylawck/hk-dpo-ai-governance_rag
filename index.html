純地端向量化引擎
Zero Third-Party API Call

100% local vector embedding execution, preventing confidential document data leakage to external APIs.

精準語義切片與防幻覺
Context-Grounded Retrieval

設定 300-400 字黃金切片與重疊緩衝區，繞過生成式模型的隨機創作層，實現「所上傳即所查詢」的硬化法規檢索。
Optimized chunking guarantees complete semantic context retrieval without generative AI hallucinations.

🔒

密碼學審計軌跡紀錄
Cryptographic SHA-256 Audit Trail

每個被檢索的法規文本切片自動生成 SHA-256 哈希值，為內部合規審計與 ISO 42001 驗證提供不可篡改的證據鏈。
Generates unique SHA-256 audit hashes for every retrieved regulatory chunk, ensuring full auditability.

🛡️ ISO 42001 & Privacy-by-Design 治理架構

🔒 資料不落地 (Zero Data at Rest)

採用 Session RAM 內存沙盒機制。用戶上傳之 PDF 文件與生成的向量索引僅存於單次會話中，瀏覽器關閉即刻徹底銷毀。
Ephemeral memory execution. Uploaded PDFs and vector indices exist only in volatile RAM and are wiped upon session end.

🔒 版權保護與合規分發 (Copyright Safeguards)

本倉庫絕對不預存或散布數字辦官方指引原文，使用者經合法途徑下載後於在地端進行載入，完全符合版權與管治規範。
Does not redistribute official PDFs. End-users upload official documents locally, strictly adhering to IP and copyright laws.
